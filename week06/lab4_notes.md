In Part 4, while trying to delete the `Library and Information Science` department, we got an error "Error 1451: Cannot delete or update a parent row: a foreign key constraint fails". MySQL blocks this deletion to preserve referential integrity because a child record (`Transfer Student` with matric number `20239999`) in the `Student` table still references that department's `dept_id`, and deleting the parent would leave an orphaned foreign key. I resolved this safely by first updating the student's `dept_id` to `Software Engineering` before deleting the empty department. Alternatively, I could have deleted the dependent student record first, or configured the foreign key constraint with `ON DELETE CASCADE` (to automatically delete child rows) or `ON DELETE SET NULL` (to set the student's `dept_id` to `NULL`).
